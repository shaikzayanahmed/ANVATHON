Section 07 / Client State Architecture & Lifecycle Handling

Strict boundary separation between Server Caches, Local UI states, and SSE live streams.

TanStack Query + Custom SSE Hooks
Tier 01: Server Cache TanStack Query v5

Handles all asynchronous REST resources, deduping parallel requests and managing background revalidation.

  • ['statutes', filterQuery]
  • ['graph', statuteKey]
  • ['conflict', conflictId]
  • ['eval-summary', benchId]
Default Stale Time: 5 minutes. Automatic window-focus revalidation enabled for active bench.
Tier 02: Local UI State React useState / Reducer

Ephemeral presentation states confined to single view modules or synchronized via URL query params.

  • selectedNodeId: string | null
  • graphZoomLevel: number
  • activeDossierTab: 'alpha' | 'beta'
  • isFolioModalOpen: boolean
No external state overhead. URLSearchParams maintains shareable deep links.
Tier 03: Live Stream State useRunEvents Hook

Real-time unbuffered message consumer managing the LangGraph execution lifecycle state machine.

  • connectionState: ConnectionStatus
  • timelineEvents: RunEventPayload[]
  • currentStage: PipelineStage
  • accumulatedTokens: number
Automatic reconnect with exponential backoff on dropped connection.
